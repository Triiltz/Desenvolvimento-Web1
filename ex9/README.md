# Exercício 09 - API REST para CRUD de duas entidades com relacionamento


Este diretório contém a solução para o Exercício 09, que consiste na implementação de uma API REST sobre as funcionalidades de um **CRUD de duas entidades (Aluno e PlanoTreino)**. O projeto, que evolui do Exercício 08, utiliza **Spring MVC (para Web e REST), Spring Security, Thymeleaf & Spring Data JPA**.
