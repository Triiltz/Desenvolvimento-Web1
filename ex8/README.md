# Exercício 08 - CRUD de duas entidades com relacionamento

Este diretório contém a solução para o Exercício 08, que consiste na implementação das operações CRUD (Create, Read, Update, Delete) para **duas entidades de sua escolha**, com persistência em banco de dados e **relacionamento entre elas**. O projeto utiliza **SpringMVC, Thymeleaf & Spring Data JPA**, e exige pelo menos 10 atributos no total, além de validação dos formulários.
